# 不依赖厂商视频 IP 的 LCD 通路

2026-11-01。状态：本机验证及静态/竖版回放实物上屏、联合guard/watchdog/UDP回归均已通过；实时业务界面仍待完成。见 [实体板结果](../../validation_runs/20261101_lcd_python/LCD1_BOARD_VALIDATION.md)。

## 选择与边界

缺陷类别是显示软件依赖无法重建的硬件接口；接口、引脚、时钟和实现必须来自同一可重建工程。原 Python/video2lcd 黑屏的具体根因未证实。本方案绕开缺失工程，不宣称已定位原黑屏原因。

最小方案：保留已验证的 PS7→AXI→B32 guard/watchdog，增加同一 50 MHz 时钟域的 AXI4-Lite LCD 帧缓冲与扫描器。复用彩条的 RGB888 引脚、DE 模式、25 MHz 像素时钟和 1056×525 总时序，显式引出 L17 复位。800×480 物理画面、480×800 Python 画布；Pillow 旋转、量化为 16 色后写入片内双缓冲，垂直消隐时换页。无需摄像头、DDR DMA、视频中断、Digilent 或商家自定义 IP。

为什么不能只改 Python：现有纯彩条没有可写画面接口，原 video2lcd 对应可重建工程缺失。相较完整重建 VDMA/VTC/动态时钟链，片内存储适合低频更新的状态屏，接口与时钟域更少。取舍是同时16色，适用于文字、流程、状态灯和简图，不适合摄像头视频或照片；目标是状态更新，不声称30/60 FPS。

### 最小设计检查

1. 结构：把显示硬件与驱动作为同一可重建接口交付，解决无法重建/接口不匹配这一类问题。
2. 使用负担：调用方只提交480×800的Pillow画布，不填写地址、时钟、页号或调色板。
3. 确定项：驱动读取BUILD_ID、尺寸、当前页和换页状态，页号由当前页推导。
4. 规模：固定当前屏幕的16色双缓冲，不引入图形服务器、摄像头或新的DMA依赖。
5. 适用范围：面向当前已确认800×480/ID4384屏幕的状态展示；不做未验证多屏兼容。

## 存储与地址

每像素4 bit，每帧192,000字节，两帧共384,000字节；每页48,000个32-bit字，8像素/字，最左像素占最低4bit。预计96个RAMB36左右，以综合报告为准；现有B32报告BRAM使用为0，器件可用140个RAMB36。画面内存不复位，首次换页前显示硬件生成的彩条，不扫描未初始化内存。

guard保持0x43C00000，LCD使用0x44000000/1MiB，50MHz域内经同一AXI interconnect连接。运行时HWH继续适配已验证的boot IOPLL分频，不修改现有B32位流文件。LCD PCLK是50MHz逻辑产生的25MHz输出，面板采样上升沿前在下降沿更新RGB/DE。

| 偏移 | 含义 |
|---|---|
| 0x00 | BUILD_ID 0x4C434431 |
| 0x04 | enable，默认1；只允许bit0 |
| 0x08 | bit0已有完整帧，bit1前台页，bit2等待换页，bit3 enable，bit4 ID已采样 |
| 0x0C | LCD ID，strap100→0x4384、001→0x7084，其余0 |
| 0x10 | 写下一页(0/1)，请求垂直消隐换页；不能提交当前页或重复提交 |
| 0x14 | 已显示帧代数，每次换页加1 |
| 0x18 | 扫描帧计数（与Python更新次数分开） |
| 0x1C | 高16bit=480，低16bit=800 |
| 0x20/0x24 | 配置时钟50MHz/25MHz，非独立测频结果 |
| 0x28 | 每页有效字节数192000 |
| 0x100..0x13C | 16个24-bit RGB调色板；首帧显示后锁定，读回可用 |
| 0x1000..0x2FDFF | 第0页，只写 |
| 0x31000..0x5FDFF | 第1页，只写 |

帧内存不提供CPU读回。非法、未对齐、只读写入、前台页写入、等待换页时写入返回SLVERR。AXI AW/W独立握手，允许响应背压；读响应保持到被接收。Python通过代数/当前页确认换页，不能把确认换页写成“实物显示已通过”。

## 先列故障模式，再实现验证

- 总线：AW/W不同拍到达、B/R背压、非法地址、非对齐、WSTRB部分写和零写。
- 内存：页偏移、每字8像素的低高nibble顺序、首尾像素、行跨字、末行。
- 显示：没有帧时可见彩条、DE每行800/每帧480、PCLK与RGB相位、复位和背光、ID采样期间三态。
- 换页：只在消隐换页、待提交页不可继续写、当前前台不可写、确认代数变化、禁用后无DE。
- Python：旋转方向、固定调色板最近色量化、输入尺寸错误、BUILD_ID错误、换页超时。
- 集成：guard原地址/50MHz不变，原RTL与软件回归、Vivado DRC/时序/资源检查、独立运行目录与回退。
- 实物：先核对新联合位流启动彩条和网络，再提交Python文字/RGB/箭头；必须由用户确认可见、方向/颜色正确，才能继续真实状态刷新。

仿真和软件测试不能替代实物验收。暂不重复把旧独立彩条位流加载到运行中的Linux。
